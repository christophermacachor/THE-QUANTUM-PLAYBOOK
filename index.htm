The Macachor Fundamental Law is a gradient-flow framework for scalar field dynamics on a compact Riemannian manifold without boundary. The energy functional is nonnegative, and the unique positive zero-energy state is ψ = M, where M = (√5 − 1)/2 is an axiomatic parameter choice.

III

Mathematical Setup

Ambient Space

Let (Mⁿ, g) be a compact, connected, smooth Riemannian manifold without boundary.

Rationale: This choice ensures: the Laplacian Δ has a discrete spectrum with a zero eigenvalue (constant functions); standard existence/uniqueness theory applies; spectral theory and stability analysis are well-defined; the setup is consistent throughout.

The Scalar Field

Let ψ: Mⁿ → ℝ⁺ be a positive scalar field. Positivity ψ > 0 is essential for the construction involving ν = 1/ψ².

The Macachor Potential

V(ψ) = ¼(ψ² − M²)²

Key property: V(ψ) = 0 if and only if ψ = ±M. For ψ > 0, V(ψ) = 0 if and only if ψ = M.

The Macachor Constant

M = (√5 − 1)/2 ≈ 0.61803398875

Axiomatic Parameter Choice

This is not claimed to be mathematically derived from the gradient-flow structure alone.

The Energy Functional

E[ψ] = ∫M [ ½||∇ψ||² + V(ψ) ] dVg
Theorem: E[ψ] ≥ 0 for all ψ in the appropriate function space.
Proof: Each term in the integrand is nonnegative.
Theorem: ψ = M is the unique positive zero-energy state.
Proof: ∇ψ = 0 → ψ constant; V(ψ) = 0 → ψ = ±M; positivity → ψ = M.
IV

Gradient-Flow Dynamics

The Reaction-Diffusion Equation

∂ψ/∂t = Δψ - V'(ψ)

with V'(ψ) = ψ(ψ² − M²). Expanding:

∂ψ/∂t = Δψ + M²ψ − ψ³

Mathematical Classification

This equation is mathematically a scalar Allen–Cahn / Ginzburg–Landau-type gradient flow on a compact Riemannian manifold.

What is novel about the Macachor formulation: the choice of variable (positive scalar field ψ); the interpretation (scalar field dynamics on a Riemannian background); the parameterization (M = (√5−1)/2 as an axiomatic constant); the proposed observable (ν = 1/ψ²); the empirical predictions (to be formulated).

Theorem: ψ = M is a stationary solution of the PDE.
Verification: For constant ψ = M, ∂ψ/∂t = 0 − V'(M) = −M(M² − M²) = 0.
Proposition: Energy is non-increasing along trajectories.
Proof: dE/dt = −∫M (∂ψ/∂t)² dVg ≤ 0.
VI

Local Stability Analysis

Linearization

Let ψ = M + ε φ, where ε is small. The linearized equation is:

∂φ/∂t = Δφ − 2M²φ

Derivation: V''(M) = 3M² − M² = 2M².

Spectral Decomposition

On the compact Riemannian manifold, the Laplacian Δ has a discrete spectrum:

0 = λ₀ < λ₁ ≤ λ₂ ≤ ... → ∞

For a Fourier mode φk ∼ eλt φk:

λ = −λk − 2M²

Since λk ≥ 0, λ ≤ −2M² < 0 for every mode, including the constant mode.

Theorem: All linear perturbations about M decay exponentially with rate at least 2M² > 0.
M is locally asymptotically stable.

✓ Note on v4.2

Unlike the compact-manifold version with the zero-mode caveat, here every mode decays with rate ≥ 2M² regardless of k = 0. The potential curvature term is sufficient. The "excluded by boundary conditions" hedge is no longer needed.

VII

Global Convergence

Open question: Does every positive initial condition converge to M as t → ∞?
Status: Open until proved.

Conditional Result

If the Łojasiewicz–Simon inequality holds for the Macachor energy functional on the compact Riemannian manifold, then every positive solution converges to a stationary solution.

Conditional Requires: energy functional is analytic; stationary solutions are isolated; Łojasiewicz exponent is known.

Stationary Solutions

−Δψ + ψ(ψ² − M²) = 0

Known solutions: ψ = M (the spatially uniform zero-energy state).

Open Question Are there other positive stationary solutions?

Hypothesis: M is the only positive stationary solution that is stable and has finite energy.
Other stationary solutions may exist but are unstable or have infinite energy.

Status

Local stability is proved. Global stability is an open problem. The existing local exponential stability result is not promoted to global asymptotic stability unless the additional argument actually establishes that.
