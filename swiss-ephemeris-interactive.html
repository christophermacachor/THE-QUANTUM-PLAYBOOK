The core astronomical calculation engine written in ANSI C. Handles planetary positions, house systems, eclipses, and date conversions. Entry point: swe_set_ephe_path() initializes the ephemeris file path. All functions are thread-safe when compiled with proper flags.

Raw JPL Development Ephemeris files in binary format. DE441 is the current standard (2026), replacing DE431. MD5 checksums provided for integrity verification. swejpl.c handles direct JPL binary reading; optimized for Android NDK builds.
